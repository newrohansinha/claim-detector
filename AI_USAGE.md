# AI Usage

Codex is used as an implementation and verification accelerator for this project. Its use is
explicit because code-generation speed is not itself the contribution of the submission.

## Codex-assisted work

- Repository scaffolding and implementation.
- Test generation and execution.
- Dataset inspection and reproducibility tooling.
- Training/evaluation orchestration.
- Plot and report generation.
- Review of code, logs, and experimental outputs.

## Human-owned decisions

Rohan Sinha owns and must be able to defend:

- The operational definition of a claim.
- Approval of challenge-set labels and rationales.
- The experimental hypotheses and interpretation boundaries.
- Manual error-analysis judgments.
- The final claims made in the report and interview.

## Verification rule

No metric, benchmark, dataset property, or deployment claim is accepted merely because Codex
generated it. Quantitative claims must trace to versioned executable code, real predictions, and
saved machine-readable outputs. Failed or negative experiments remain reportable results.
